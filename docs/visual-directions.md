# Visual Directions

## 1. Cinematic Investor Scroll

Chosen implementation direction. The site behaves like a premium investor story:
large photographic chapters, deep teal surfaces, yellow typographic emphasis,
native financial charts and controlled reveal motion.

## 2. Surf Platform Narrative

More lifestyle-led and brand-forward. This would increase turquoise/water
accents, use larger photography moments and make the investment data feel more
like supporting proof.

## 3. Financial Command Story

More sober and finance-led. This would emphasize tables, benchmark data and
investment structure with tighter spacing and less immersive photography.

## Decision

The implemented direction is `Cinematic Investor Scroll` because it best matches
the request: investor-grade, modern, premium and less crowded than the source
PDF while retaining the Gemswell deck DNA.
